Using `queue_free.call_deferred()` (or `call_deferred("queue_free")`) means the node is not removed from the scene tree until at least the end of the current frame. Since `spawn_round_players` continues immediately after this `await`, it will attempt to add new nodes with the same names (peer IDs) while the old nodes are still present in the tree, causing Godot to rename the new nodes (e.g., to `"123@2"`). This breaks multiplayer synchronization. 

Use `remove_child()` before `queue_free()` to ensure the node name is immediately available for reuse in the same frame.

```
	for node in nodes_to_free:
		if is_instance_valid(node):
			if node.get_parent():
				node.get_parent().remove_child(node)
			node.queue_free()
```
